# Campo Municipal de Hockey Pablo Negre

Modelo low-poly estilizado del campo de San Fernando, creado en Blender 5.0.1.

## Contenido

- `pablo_negre.blend`: escena editable.
- `pablo_negre.glb`: exportación para el juego.
- `pablo_negre.png`: render de referencia 1600x900.

## Elementos modelados

- Campo de hockey 91,4 x 55 m con césped verde a franjas.
- Líneas reglamentarias: bandas, línea central, 23 m, áreas de disparo y puntos de penalti.
- Dos porterías con marco y red.
- Grada azul de 300 asientos (6 filas x 50).
- Vestuarios, casas del entorno, árboles y valla perimetral.
- Cuatro torres de iluminación LED.
- Carteles de San Fernando Hockey y placa Pablo Negre.
- Pista perimetral roja y base de hormigón.
