# Jugador predeterminado de hockey hierba

Iteraciones del jugador low-poly estilizado:

- `v1/`: blockout inicial.
- `v2/`: brazos reposicionados, equipamiento limpio y rig de 21 huesos.
- `v3/`: cuerpo unificado con skinning, articulaciones y cuatro animaciones.
- `v4/`: **versión de producción** con malla unificada, kit rediseñado, texturas PBR, LODs, colisión, cuatro animaciones y evaluación técnica.

La versión activa para el juego es:

```text
v4/default_hockey_player_v4.glb
```

## v4

- LOD0: 10.348 vértices / 17.196 triángulos / 10 materiales.
- LOD1: 8.598 triángulos.
- LOD2: 4.291 triángulos.
- Rig de 21 huesos.
- Acciones: `Idle`, `Run`, `Pass`, `Shoot`.
- 13 texturas PBR de 512×512.
- Cápsula de colisión de 508 triángulos.
- GLB autocontenido con skin de 21 joints y las cuatro animaciones.

Consulta `v4/README.md`, `v4/evaluation_report.md`, `v4/references.md` y `v4/asset_manifest.json` para la ficha completa, el gate técnico y las fuentes de diseño.
